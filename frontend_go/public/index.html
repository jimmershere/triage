The HEDI pipeline

  1. Secure upload: TLS 1.2 Go front end locks down every file.
  2. Async ingest: FastAPI signs, stores, and launches jobs into RabbitMQ.
  3. Python 3.12 workers: Validate, enrich, and generate friendly acks.
  4. PostgreSQL vault: Originals + translations ready for reprint, anytime.
